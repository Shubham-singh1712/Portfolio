Premium Developer Portfolio

A highly polished developer portfolio featuring a custom aspect-ratio layout system, high-performance canvas spark simulations, and a bespoke glassmorphic dark-mode design system.

View Source Live Demo

Problem Statement

Generic templates fail to captivate visitors, while typical responsive layouts often stretch or clip complex background mockups, leading to an unpolished visual experience across varying screen dimensions.

Solution

Built a bespoke design system with CSS custom properties, using centered layout containers fixed to specific aspect ratios (16:9 for desktop, 9:16 for mobile). This ensures that overlay interaction buttons and progression trackers scale cleanly. Additionally, implemented a canvas spark system reactive to mouse movements for subtle micro-interactions.

Key Features

  • ✦ Bespoke Aspect-Ratio Containers (16:9 / 9:16)
  • ✦ Interactive Canvas Emitter (Sinusoidal Spark Particles)
  • ✦ Amber Frosted Glassmorphic Components
  • ✦ Intersection Observer-Powered Entrance Reveals
